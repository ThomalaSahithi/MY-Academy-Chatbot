# MY Academy Chatbot

## Project Overview
MY Academy is a responsive educational website that introduces learning opportunities, showcases courses, and helps students make course enquiries. It includes an AI chatbot integrated with n8n to assist students with their questions.

## Features
- **Course Information:** Displays available courses, including Python Basics and Data Engineering Basics.
- **AI Chatbot:** Provides a chat interface for student enquiries using n8n.
- **Course Enquiries:** Allows students to express interest in a course.
- **Contact Form:** Collects student names, email addresses, course interests, and enquiry messages.
- **Responsive Design:** Provides a user-friendly interface across desktop and mobile devices.
- **Interactive Navigation:** Allows users to explore courses, learning information, and contact sections.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- n8n
- OpenAI Chat Model
- GitHub
- Vercel

## Workflow
The n8n workflow connects the website chatbot to an AI-powered conversation system that processes student messages and generates responses.
